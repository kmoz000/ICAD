# Turbojet ground-demonstrator development program

Program state: **DEVELOPMENT — Gate 0 open**

The objective is an instrumented single-spool turbojet that may be operated only
in a professionally engineered, contained ground-test facility in Morocco. EASA
CS-E Amendment 8 is an assurance framework, not a certification claim. Flight,
public operation, fabrication release, and fueled testing are prohibited by the
current state.

## Authority and roles

- Program accountable manager: open.
- Chief engineer and configuration authority: open.
- Independent safety reviewer: open and organizationally separate from authors.
- Qualified partners: cycle/aerodynamics, combustion, structures/lifing,
  rotordynamics/bearings, controls, manufacturing/NDT, and test-cell operation.
- Moroccan authority, environmental, workplace, fire, fuel-storage, and noise
  applicability: written determinations required by Gate 0.

## Controlled gates

1. Gate 0 — requirements, CS-E applicability, Moroccan permissions, preliminary
   hazard analysis, partner appointments, and configuration plan approved.
2. Gate 1 — cycle/mean-line, thermal, structural, rotordynamic, containment,
   controls, and architecture trade-study evidence independently accepted.
3. Design Freeze R1 — ICAD geometry regenerated only from accepted Gate 1 inputs.
4. Manufacturing release — drawings, material allowables, processes, FAI, NDT,
   balance, and conformity records accepted.
5. Test readiness — contained facility, calibrated acquisition, remote controls,
   abort logic, fuel/fire provisions, procedures, and independent review accepted.
6. Progressive test — motoring, lubrication, light-off, idle, transients, derated
   points, and envelope expansion under the test director.
7. Validation — approved envelope, endurance schedule, teardown, dimensional/NDT
   inspection, anomaly closure, limits, and final report accepted.

Changing the source, a controlled input, material definition, or load case makes
linked evidence stale. No repository check can substitute for a partner signature,
permit, conformity inspection, calibrated test, or authority finding.
