A compiler, not a macro layer

Geometry that can explain itself.

ICAD owns the language, semantic model, geometry, topology, and exporters—so every result remains inspectable from prompt to manufacturing artifact.

01

Deterministic language

Typed dimensions, constraints, profiles, features, assemblies, mechanisms, and animation compile into a canonical intermediate representation.

  • Human-readable source
  • Stable diagnostics
  • Persistent topology references
02

Native geometry engine

Primitive and programmable geometry, boolean CSG, analytic surfaces, triangulation, topology queries, mates, and joint solving in modern C++.

03

Agent-native feedback

Structured inspection, visual snapshots, manufacturing validation, topology evidence, and MCP tooling help agents reason about what they built.

04

Production outputs

Build complete packages with CAD, mesh, drawing, scene, BOM, topology, and manufacturing files—then read them back in acceptance tests.

The agentic build loop

Intent in. Evidence out.

A short prompt can create a complete editable design. Every step remains available to inspect, revise, compile, and verify.

  1. 01
    Describe

    State the part, assembly, mechanism, materials, and engineering intent.

  2. 02
    Compile

    ICAD parses and validates deterministic source into geometry and topology.

  3. 03
    Inspect

    The native studio and structured reports expose the design to people and agents.

  4. 04
    Manufacture

    Export interoperable CAD, meshes, drawings, BOMs, and evidence packages.
